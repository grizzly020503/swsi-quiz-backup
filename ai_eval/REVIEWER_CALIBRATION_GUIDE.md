# SWSI 申論回饋：模擬閱卷校準指南（供人工審查，非官方評分）

> 更新：2026-10-24。用途：讓人工審查者評估 **AI 對學生申論的回饋是否公允、具體**，不是提供考選部的閱卷配分，也不是替學生直接打國考分數。與 Draft PR #425 / Issue #381 搭配使用。此檔 **不含任何真實個案或實習錄音內容**。

## 1. 可查證的閱卷制度與不可推論的事

**可查證的制度：**依《閱卷規則》（112-12-28 修正）第 4 條，實際國考閱卷前，相關委員先商定評分標準，必要時先取部分卷試評；第 6 條原則上單閱，亦可分題或平行兩閱；第 11 條一般應對作答內容圈點或用符號標明正誤；第 17 條可將紙本試卷影像顯示在電腦上評閱。是否採哪一種方式，不能在不知道當次科目資料時斷言。第 28 條要求實際閱卷與評分資訊保密。

**不具備的證據：**本專案未取得社工師國考某次某題未公開的正式評分標準、閱卷委員內部評閱紀錄或實際逐卷評分；也未實際觀察閱卷現場。從授課老師或閱卷委員的個別經驗得知「先注意標題、考點、架構」，只能用來改善答案的可讀性和評語，不代表「只有標題就足夠」，更不代表普遍且固定的閱卷秒數、扣分表或配分。

來源：
- [全國法規資料庫：閱卷規則](https://law.moj.gov.tw/LawClass/LawAll.aspx?PCODE=R0020018)（第 4、6、7、11、17、28 條）
- [考選部：典試法規相關說明](https://wwwc.moex.gov.tw/main/news/wfrmNews.aspx?kind=7&menu_id=1968&news_id=2027)（典試法對實際作答內容的客觀評量及不得提供申論參考答案）
- 本專案正式試題來源：`incoming/115030.json` 的 `E-115-1-SW-1`；正式題文字以考選部原始 PDF 為準。

## 2. SWSI 建議的人工校準順序（產品品質規格，不是官方閱卷程序）

1. **先看題，不先看舊指南：**依正式題幹拆出要求的每一件事，以及題目**明確指定**的理論、觀點、子題和比較面向。不可把自己喜歡的理論取代題目指定理論。
2. **確認實質內容：**對照學生的原句（或經學生確認的手寫辨識文字）判斷「有回答且合理／有回答但不充分／未回答／有錯或待查證」。空標題或只提關鍵名詞不等於有解釋。若題目只要求列舉名詞，短答可能已足夠，仍須依該題要求判斷。
3. **接受合理的替代路徑：**題目允許自由選擇概念、論述次序或實例時，承認不同的專業上可辯護的選擇。意思相同的句子不因缺少 SWSI 指定關鍵字而被判錯。不能把「都不一樣」延伸成「任何答案都正確」。
4. **區分事實、分析與處遇：**重視是否交代依據及關係，是否把觀察當事實、把假設當定論，是否忽略自決、保密、安全與權力差異。僅在題目要求時才要求特定倫理／實務面向，不任意增加題意外的硬性配分。
5. **只指出可驗證的缺口：**回饋要能引用實際學生文字、說明哪一問或哪一個論證環節不足，提供 1–3 個優先修正動作；不假造學生原文，不宣稱國考幾分或官方閱卷老師必定如何評分。
6. **複核不確定事項：**對法條適用日期、政策版本、特定理論出處及不同學派爭議，標示需查證；若人工審查者有分歧，紀錄兩種解釋及查證需求，而不是強迫產生唯一答案。

## 3. 同題、不同合理答法的校準例子（合成，未經真人閱卷校準）

**示例題：115 年第一次《社會工作》申論第 1 題。** 題意要求：(A) 自行選用家庭系統的三個概念來說明家人關係；(B) 說明家庭生態圖的理論基礎；(C) 說明家庭生態圖能提供哪些訊息。這題的「三個概念」並未指定只能是哪三個。以下都是**合成的審核提示**，不是正式國考標準答案。

| 內容路徑 | 人工校準時應注意 |
|---|---|
| **作答 A**：以「次系統、界線、循環因果」說明家庭成員互相影響；再用生態／開放系統觀點說明生態圖如何呈現外部支持、壓力與資源流動 | 若三概念確有解釋，且有回答 B、C，應依實質內容評價，不要求套用固定段落順序 |
| **作答 B**：以「家庭角色、恆定／回復平衡、回饋機制」解釋家人的互動與調適；再說明人與環境互動、生態圖中的社區／工作／福利網絡及關係強弱 | 概念選法與 A 不同；不能只因沒寫「次系統」或「界線」就判錯；仍需檢查概念定義、互動例子及 B、C 是否足夠 |
| **作答 C**：只寫「一、家庭系統三概念；二、家庭生態圖理論；三、資訊」，沒有三概念名稱、意義或任何說明 | 有標題不等於已回答；應指出缺少實質論述 |
| **作答 D**：全篇只說家系圖是三代血緣圖，沒有回答家庭生態圖的理論和外部關係 | 即使畫圖或格式整齊，仍漏 B、C，且有混淆家系圖與生態圖之風險 |

**反向檢查：**若某題明白指定只能用某理論或某幾個概念，就不能主張「學生想用其他理論也算完整」；判斷必須回到正式題意。

## 4. 人工審查 AI 回饋，不是由 AI 代替老師評學生

現有 `ai_eval/golden_set.json` 20 筆是**AI 回饋品質測試案例**，不是 20 題待重寫的國考申論指南。人類審查應針對**模型回饋本身**檢查以下五維度（依現有 v1 合約，0–2 為人工評 AI 回饋的維度，不是學生國考分數）：

| AI 回饋維度 | 判讀問題 |
|---|---|
| `task_alignment` | 是否尊重題目指定任務，沒有以舊 SWSI 架構取代題意？ |
| `answer_specificity` | 是否指出學生真的寫了什麼、漏什麼、如何修正？有無靠空泛讚美蒙混？ |
| `uncertainty_discipline` | 是否避免虛構法律、學者、時間、精確扣分；疑義有否提出查證？ |
| `pedagogical_usefulness` | 看完能不能知道下次怎麼寫得更好？ |
| `non_authoritative_tone` | 是否清楚是練習回饋、不冒稱國考官方評分？ |

人工檢查須防兩種方向的誤判：**假陰性**（換同義說法就被當成漏答）、**假陽性**（只有標題或關鍵字就被當成已完整作答）。應以內容證據為基礎，不能單靠詞彙有無作語意評分。

> **狀態與發布閘門：**本文件僅提供 reviewer 校準規格；沒有取得閱卷委員簽名或真實教師對以上 A–D 的專業校準，也沒有以任何合成案例取代 20 筆既有模型輸出的實際人工五維評分。不可填寫 `human_review_completed=true`、不可降低分數門檻或變更 Model/Prompt/Golden Set 以換取綠燈。真實學生、個案及實習督導的錄音或未匿名逐字稿不得放進 GitHub、公開 Golden Set 或第三方 AI 請求。

## 5. 審查者最小記錄格式（僅匿名資料）

```text
案例代號（不得含學生或個案姓名）：
正式題目要求 A/B/C：
學生已回答（請引用其作答的匿名化原句）：
未回答／部分回答／需查證處：
不同但合理的表達／理論路徑：
AI 是否誤將參考指南當唯一答案：
AI 是否把只有標題或關鍵字判成完整：
五維回饋品質（每維 0/1/2，附具體理由）：
人類審查結果：待複核／有條件接受／拒絕
```
