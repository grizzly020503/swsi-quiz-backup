# SWSI 第二輪互動設計：重新建立視覺語言

**Owner 已否決第一輪「暖白閱讀室」的視覺方向。PR #604 仍是 Draft，第一輪的 CI 通過不代表設計獲准，禁止合併或發布。**

本目錄是與正式產品隔離的第二輪首頁／刷題互動稿，不是已經完成的全站改版。沿用正式產品的功能名稱，自訂兩道展示題；不讀寫正式題庫、帳號、AI、統計或學習紀錄。原有候選產品程式暫留，避免未確定的方向大量改動全站。

| 方向 | 構成與視覺 | 刷題構成 | 動態 |
|---|---|---|---|
| A 藍白學習介面 | 高彩度藍色主操作區、不對稱雙區，白色路徑與水平工具列 | 左側科目／題序，右側明確閱讀面；手機收為單欄 | 標題進場、幾何圖形一次組合、選答與解析回饋 |
| B 深色專注介面 | 深色無卡片主舞台、黃綠色圓環、橫向入口列 | 放大的題序與題目分區，深色閱讀面 | 圓環一次進場、按鈕按壓與解析切換 |
| C 珊瑚橘開放編排 | 大字標題、垂直色線、珊瑚橘行動帶、開放的入口清單 | 單一開放頁面、橫線選項、不套用圓角卡片 | 標題進場、選項選取與送出回饋 |

初步推薦 **A** 作為全站延伸基礎：首頁有足夠識別性，題目區仍適合閱讀；B 適合偏好深色介面者，C 的個性最強。此為設計判斷，未宣稱 Owner 已選定。

## 操作

以 HTTP 提供本目錄，開啟 `index.html?theme=a`（也可選 b/c），右上 A/B/C 切換方向。點「開始刷題」可選答、送出、看解析、下一題、完成。支援標準／放大字級，其他功能入口明確說明這份稿的範圍。兩道展示題不屬於官方題庫。

## 字型與動態

第一輪圖片有 CJK 字型回落的風險；本輪直接附上 Noto Sans CJK TC 的展示文字子集（Regular／Bold），不依賴測試容器或外部字型網路服務。OFL 授權附於 `FONT-LICENSE.txt`。這個子集只適用本概念稿，不應直接拿去覆蓋完整正式題庫的中文字型。

動畫為 CSS transform/opacity 與狀態切換；無 WebGL、無無限循環、無捲動鎖定、無外部動畫套件。進場 550–900ms，按壓與選取約 180ms，解析 250ms。`prefers-reduced-motion` 關閉動畫及過場。讀題時沒有背景連續移動。

## 驗收

`Taste Second Round Concepts (NO DEPLOY)` 在隔離 Chromium 檢查三方向 × 390/768/1024/1440px，擷取首頁、刷題、解析、長題幹及長選項／放大字級，並錄製 390px 的實際操作動畫。測試阻擋所有非 localhost 網路請求，確認字型載入及兩題操作流程。

這些測試只驗證概念稿，不代替採用新方向後的全站回歸、真機、登入與正式 AI 驗收。Taste 是手動參照官方設計與動態指引，Plugin 安裝限制不變，未宣稱已安裝或取得官方 Gate PASS。
